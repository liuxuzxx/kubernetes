# 1. 概述

进入下一个探索方向:Pod 的创建过程

Pod 的生命周期管理是整个 K8S 的核心部分,k8s 的作用就是调度,所以如何分配资源，如何和 node 沟通,都是 k8s 的核心工作.

我们就先看下 Pod 是如何创建出来的,但是限于复杂性,所以我们决定先从和 kubelet 沟通的地方开始下手.

# 2. Pod 的创建过程

## 2.0 思考过程

从经验可以获取到如下的点:

1. Pod 其实是多个 Container 的组成,那么 Container 是 docker/containerd/cri-o 这些组件管理的
2. 然后镜像也是 CRI 的实现管理的.那么肯定是要和 CRI 的实现进行交互,或者说是通信,并且肯定会有地方调用这些方法
3. kubelet 就是担当一个指挥者的角色而以,并没有自己去实现底层

那么我们如何理顺整个过程:

1. 我们先去查找拉取镜像的地方.这个地方肯定是 Pod 的启动的第一个步骤
2. 接着我们就顺藤摸瓜向上查找整个流程.
3. 我们尝试在不借助于 AI 的帮助下,去学习和思考整个流程,学和思的关系.
